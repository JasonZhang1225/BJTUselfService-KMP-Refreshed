# 交大自由行 KMP `1.7.8-Liquid`

发布日期：2026-09-21

这是一次以 iOS Liquid Glass 原生体验为主的版本更新，同时收口课程表、同步、校历周位和跨平台构建中的一批问题。

## 重点更新：iOS Liquid Glass

- 新增 iOS 原生导航壳：使用 UIKit Tab Bar 和独立导航栈承载首页、课程表、成绩、作业、物理在线和更多六个一级入口，物理在线开关切换时不再出现错误选中或跳转。
- 统一原生标题栏：标题、返回、日历、同步状态和刷新动作使用 UIKit 导航栏与 SF Symbols，保持标题居中和稳定的触控区域。
- 弹窗改为原生 sheet：成绩、课程、考试、课件、筛选、日历、数据变动和同步状态等入口使用系统 detent、抓手、关闭按钮和材质，在深色模式下不再套用宽屏 Material/KMP 弹窗。
- 同步状态面板重新收口：移除多余说明和嵌套内框，压缩行高；Android 一页可完整显示，iOS 根据内容使用半屏/全屏 detent，macOS 使用扁平面板。
- 课表“前往日期”使用 iOS 原生日期选择器，默认半屏显示；“今天”放入原生导航栏动作，不再悬空在日历底部。
- 首页刷新反馈与同步入口统一：刷新时显示原生 spinner，点击状态可查看同步面板；物理在线由首页宿主自动启动同步，其他页面复用同一状态。

## 补丁：标题栏真玻璃与全页内容穿栏（与本提交绑定）

- iOS 原生标题栏改用真 `UIGlassEffect`（Regular）覆盖层：内容滚进栏后呈现液态玻璃；顶部保持透明，单标题。
- 排查结论（实机验证）：iOS 27 下手写 `UINavigationBarAppearance` 的 `configureWith*` 无效，须显式设材质；`sharesBackground = false` 会让系统根本不建栏背景，已移除。
- 首页、成绩、考试、作业、更多、教室列表、占用列表、作业详情、邮件详情、物理在线及详情、设置、日历、成绩单支持内容穿栏；课表、课件、教室详情、占用详情因固定头挡住视口，保持静态栏（可单独开关，不影响其他页）。

## 其他改进与修复

- 校历相邻教学周之间的空档展开为“非教学周”，并同步用于首页日程、课程表周选择、日期跳转、日历导出和教室占用查询。
- 修复课程表 Pager 在切换课表、跳周和动画过程中来回闪烁的问题。
- 刷新管线增加会话状态识别和恢复路径，减少长期搁置后把登录失效误报为响应结构解析错误。
- 统一 iOS 深色模式下的登录提示、数据变动、成绩/作业/考试详情、文件下载和设置类操作的 sheet 视觉与关闭行为。
- 修复紧凑作业页明文传输提示固定遮挡作业卡片的问题；课件详情和考试详情在长内容下保留完整底部操作。
- 完善密码记忆迁移、安全烟测隔离、课程类型筛选、物理在线入口和邮箱/课件刷新状态处理。

## 已知限制

- iOS IPA 未签名，不能直接安装到真机；请使用合法 Apple Developer Team 重新签名后侧载。
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在系统安全设置中确认。
- 物理在线、旧教学平台作业/课件链路仍受学校网络和原站服务状态影响；真实作业提交、邮箱写信/回复等会改变远端数据的操作请单独确认。
- Android 本版默认提供 `arm64-v8a` 构建；小组件和系统通知仍不在本版本范围内。
