# CITEL 接口调查与实现

调查日期：2026-10-07（北京时间）。通过用户已打开的 Chrome/CDP 登录并观察学校站点，不包含密码、Cookie、sesskey、logintoken 或个人附件。分支：`codex/CITEL`。

## 已验证的接口

站点根路径：`https://citel.bjtu.edu.cn/mlsv3`。CITEL 使用独立 Moodle 用户名/密码登录，未观察到物理在线使用的 CAS/OAuth 握手。

| 用途 | 方法与路径 | 数据来源 |
| --- | --- | --- |
| 登录表单 | GET `/login/index.php` | 表单含 username、password、anchor、短期 logintoken |
| 登录 | POST `/login/index.php` | 发送当次表单 token，Cookie jar 维护 MoodleSession |
| 仪表板 | GET `/my/` | 内嵌 M.cfg.sesskey，供只读 AJAX 使用 |
| 已选课程 | POST `/lib/ajax/service.php?info=core_course_get_enrolled_courses_by_timeline_classification&sesskey=…` | JSON 批量协议；classification=all、offset、limit=50、sort=fullname；响应 courses 与 nextoffset |
| 课程活动 | GET `/course/view.php?id=…` | `#region-main li.activity` 中的 assign/programming 链接 |
| 编程练习总表 | GET `/mod/programming/index.php?id=课程ID` | 个人评测状态、开放/折扣/最终截止时间、迟交许可 |
| 编程练习详情 | GET `/mod/programming/view.php?id=活动ID` | Grade、Discount、可选 `#time-table` |
| 书面作业详情 | GET `/mod/assign/view.php?id=活动ID` | activity-dates 与 submissionstatustable |

课程 API 的名字与参数首先从网站 `blocks/myoverview/amd/src/repository.js` 和 `view.js` 核对，再以当前会话实际调用验证。侧栏只列出当前课程，API 还返回历史课程，因此不得用侧栏代替完整课程清单。已观察到当前课程和历史课程两种样例。

## 折扣与截止的区别

- 当前编程练习显示 `Discount: 1`，折扣时间与截止时间相同，允许迟交。
- 历史编程练习显示 `Discount: 0.8`，折扣时间为北京时间 7 月 18 日 00:00，截止时间为 7 月 25 日 00:00，不允许迟交。
- 详情页有时省略整个时间表；同一题在编程总表仍有三段时间。先读总表再补充详情，详情缺字段时保留总表数据。
- 总表时间单元格为 `yy-MM-dd HH:mm-yy-MM-dd HH:mm`，换行后给第三段时间。第三段尾部的 `+` 表示允许迟交，与详情 `Allow late: Yes` 相符。
- Grade 是编程题的题目分值，不能用它判断个人是否完成。个人通过信号取总表 `AC: Accepted`。书面作业取 `Submitted for grading`。
- 没有观察到未来分数折扣的完整计算公式。显示站点给出的倍率及节点，未提供倍率时明确显示未知，不按时间自行推算分数。
- 书面作业样例没有折扣字段，不套用编程练习的规则。

## 实现行为

独立 CITEL 作业入口；总开关位于应用设置“功能开关”，与物理在线、物理实验同组，同时控制入口、自动同步和首页日程。开启后默认在“应用”中，可通过底栏定制加入底栏。应用设置内，物理实验和 CITEL 开关左侧的“设置”按钮分别进入账号设置二级页；保存有效账号密码后，功能名称右侧显示“已配置”。CITEL 作业页不再保留账号设置入口，物理实验主页面只展示实验和时长设置。账号设置不改变功能总开关；“已配置”代表有可用的已保存凭据，不代表本轮网络同步成功。两个账号设置页共用简洁表单，保存账号即写入平台安全存储；密码框留空时沿用同账号密码，已配置的空密码框显示“已填写过密码”。保存时只显示转圈的“正在同步”弹窗，账号页不显示顶栏或正文加载条。开启后启动/真正回到 App 时自动同步，首页主动刷新也同步；进入 CITEL 列表只加载缓存，不自动刷新或探测会话。Android 使用 Activity started 数量区分页面切换与应用前台进入，避免导航触发全量同步。

界面复用应用主题、原生导航和 AppleSheet；参考项目 Apple Design 技能。默认按截止时间由近到远排序，筛选弹窗支持课程、隐藏已过期、隐藏已提交，以及原顺序/由近到远/由远到近。日期统一用北京时间，支持英文/中文日期、两位年份和 AM/PM。折扣/截止时间不同时生成两个首页节点，相同时合并一个。北京时间 00:00 的截止节点沿用首页的前一日归属规则。

作业列表对齐原作业页的数量摘要、筛选入口和状态筛选。账号页面使用可滚动全屏表单与键盘避让，Android 两个 Activity 显式配置 adjustResize，输入框在键盘布局变化后自动滚动至可见位置；主登录与物理实验账号输入也使用同一处理。

每次幂等页面读取遇到登录页（包括 HTTP 200 登录 HTML）时，获取新的 logintoken 重新登录并重试该读取一次。只读课程 AJAX 遇到 invalidsesskey 等会话错误时也恢复一次。所有跳转逐跳验证 HTTPS、域名、端口和路径，拒绝跨域及登录 POST 的 307/308 重放。失败保留完整旧快照，避免半份数据覆盖缓存。缓存按学校账号隔离；更换 CITEL 用户清空旧作业。请求日志隐去 username/password/logintoken，短期会话字段不写入缓存。

按最新 UI 要求，物理在线与 CITEL 一级页面复用原作业 `HomeworkSummaryBanner`，卡片使用原作业字号、间距与布局。三个来源卡片右上角统一显示绿色“已提交”或琥珀色“未提交”标签，卡片正文不再重复提交状态文字。物理在线详情保留原有分区，文件操作进入上传弹层；物理在线与 CITEL 共用 `AssignmentFilesEditor` 和 Moodle 文件协议，物理在线仍保留独立最终提交。CITEL 紧凑端使用与原作业/物理在线一致的原生详情导航，宽屏保持详情弹层。

物理在线与 CITEL 筛选条件采用 `AssignmentFilters`，按学校账号与来源分别持久化课程 ID 集合、隐藏已过期、隐藏已提交和排序方式。页面重进及数据库重开后恢复；只存条件，不存筛选结果。每次页面更新按当前完整作业数据和当前时间重新计算可见列表，物理在线支持跨课程统一列表。原作业原有筛选持久化保持有效。

原生二级页校验现在允许所有可从应用目录进入的功能。修复底栏定制移除作业、成绩、课程表等入口后，它们从应用目录启动即关闭的问题；HOME/MORE 和未知路由仍不属于二级页面。

### 文件保存与最终提交

- CITEL 实验报告：读取 `action=editsubmission` 表单和 `M.form_filemanager.init` 配置，以页面里的 upload 仓库编号上传；原文件移除只改本次草稿区，再 POST `action=savesubmission`。保存后读取正式附件列表，逐一核对新旧文件。服务器仍提供 editsubmission 入口时可继续修改。
- 物理在线：保存文件后仍是草稿的作业需要用户点“最终提交”。从 `action=submit` 读取确认表单，实际 POST 使用 `action=confirmsubmit`；提交声明原文展示给用户并要求勾选。保存草稿不会把首页标为已完成，最终提交后刷新列表和首页日程。该表单行为与 [Moodle 官方确认表单源码](https://raw.githubusercontent.com/moodle/moodle/MOODLE_400_STABLE/mod/assign/submissionconfirmform.php) 一致。
- 两站的共享文件区支持新增、移除、同名替换、文件大小/数量/类型预检；CITEL 现场 upload 仓库编号为 5，编号 4 是 recent，不能使用固定默认值。短期表单和文件区上下文只用于当次操作。保存或最终提交的响应不确定时不自动重放 POST。
- CITEL 编程练习：从提交页读取语言选项和文件上限，用 `sourcefile` 多段文件字段提交一个代码文件；提交前后核对个人提交次数，评测运行中不标为完成。原智慧教学上传、附件下载和提交说明继续保留。
- 首页：CITEL 开始、折扣、截止使用独立事件类型；折扣与截止同一时刻时合并一个节点。未提供折扣信息的来源展示“平台未提供”，不虚构日期。草稿状态缓存后仍不会当作已完成。

## 验证

新增业务测试覆盖日期、八折样例、编程详情缺时间表、书面提交状态、节点合并、分页、会话恢复的次数限制、跨域拒绝、凭据日志脱敏、账号切换、缓存保留、关闭同步和密码记忆退出。使用真实 Compose 组件生成浅色、深色、宽屏、大字号及设置弹层截图，查看排版。

Windows 共享层及宿主、Android 共享层编译与相关回归测试通过。新增 Moodle 文件操作测试覆盖新增/删除/同名替换、限制校验、草稿与最终提交、提交声明、响应丢失不重放；编程提交测试核对语言、文件字段、提交次数和评测中的状态。渲染测试包含三来源卡片对比，以及 CITEL 实验报告/编程练习详情、浅色/深色/大字号。

Android 检查只编译共享模块，不打签名包。Windows 无法运行 iOS/UIKit 编译，未在本轮验证 iOS 真机和应用内真实账号登录。真实网站接口调查使用用户授权的 Chrome 登录会话，只查看页面和编辑表单；本轮没有上传、移除或最终提交用户的真实作业。

首页日期格统一统计智慧教学、物理在线与 CITEL 的开始/截止事件：黄色点+数字表示开始，红色/绿色分别表示未提交/已提交的截止项。开始图例常驻，与截止图例同一行。折扣事件仍显示在日程详情，但不重复计为截止数量。首页摘要不再附加来源说明；非 iOS 的“今”按钮紧邻“首页”标题右侧，iOS 导航布局保持原样。

账号设置保留各自网站的可点击链接提示。保存后验证/同步成功才自动返回设置页；失败保留当前表单并显示明确的“同步失败”原因，密码配置仍保留以便重试。功能关闭时也允许主动保存并同步验证，但不改变功能开关。首页存在任何等待项时不显示成功勾选；CITEL 右上角改用文字显示同步状态。被取消的 App 启动同步不标记为已完成，允许同一前台代次重新尝试。
