# 交大自由行 KMP 1.7.7-KMP

## 新增

- 首页数据变动增加物理在线。
- 桌面端支持清除全部本地数据。

## 优化

- 课表列表按课程类型着色。
- 加强本地账号和缓存保护，改善卸载后凭据残留的处理。

## 修复

- 修复未读邮件标记与首页新邮件数量不准确，打开邮件后即时更新未读标记。
- 修复同步进度条出现时页面高度跳动。

## 版本

- Android `1.7.7-KMP`（versionCode `18`，默认 `arm64-v8a`）
- iOS `1.7.7-KMP`（Build `18`，未签名 IPA）
- macOS / Windows 安装器数值版本 `1.7.7`

## 安装说明

| 文件 | 说明 |
| --- | --- |
| `BJTUSelfService-KMP-*-arm64-v8a.apk` | Android arm64-v8a，包名 `team.bjtuss.bjtuselfservice.kmp`。本地与 GitHub Actions 使用同一上传签名，可覆盖安装 |
| `BJTUSelfService-KMP-*-iOS-unsigned.ipa` | iOS 未签名，需侧载自签 |
| `BJTUselfServiceKMP-*.dmg` | macOS Apple Silicon |
| `BJTUselfServiceKMP-*.msi` | Windows x64 系统级安装 |

- Windows MSI 使用同一 UpgradeCode，支持同为 `1.7.7` 数值版本的安装包覆盖升级；建议直接运行 MSI，不要先卸载。
## 安装注意事项

- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/blob/main/docs/iOS-sign-guide.md)
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行\ KMP.app`
- 近期版本的更新日志，参见[Release Notes](docs/releases)
- 物理在线的自动同步依赖校园网，离开校园网时只能读取已有缓存；真实文件提交仍需在可编辑作业上继续验收。
- 邮箱写信/回复已完成协议和界面接入，但真实发送、删除、移动、转发及附件写操作仍需单独验收。
