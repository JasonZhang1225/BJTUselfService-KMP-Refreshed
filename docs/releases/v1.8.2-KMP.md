发布日期：2026-10-07

改版首页与应用入口，支持自定义底栏，并优化物理实验、教室查询和跨平台界面体验。

## 更新内容

- **自定义底栏**：固定“首页”和“应用”，可添加常用页面并长按调整顺序。旧版首次升级会重置为两项并显示确认引导，后续更新保留自定义，不再重复提醒。
- **首页日程**：按课程、考试和物理实验分类展示，增加回到今天入口，优化切周动画和物理作业显示。
- **物理实验与教室查询**：设置中增加独立功能开关，整合实验课表及教室空闲、占用查询，优化紧凑布局。
- **iOS 界面**：统一滚动玻璃顶栏的处理，修复短列表回弹时模糊不同步，优化页面转场、底栏与安全区显示。
- **其他改进**：优化课件加载、宽屏侧栏图标与更新提醒，支持推迟更新检查。

物理实验和物理在线同步需要校园网，可在设置中开启相应功能。

## 构建产物

| 文件 | 说明 |
| --- | --- |
| `BJTUSelfService-KMP-1.8.2-arm64-v8a.apk` | Android arm64-v8a 签名 Release APK，versionCode `24` |
| `BJTUSelfService-KMP-1.8.2-iOS-unsigned.ipa` | iOS arm64 未签名 IPA，构建号 `24`，需自行签名后侧载 |

## 安装注意事项

- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/blob/main/docs/iOS-sign-guide.md)
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行 KMP.app`
- 近期版本的更新日志，参见[Release Notes](docs/releases)
