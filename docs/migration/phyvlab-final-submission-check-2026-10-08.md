# 物理在线：保存与最终提交核对

分支 `codex/Duo`。仅在 Windows 修改共享代码和测试，不向真实作业发送上传或最终提交请求。

原有 Moodle 协议已经分离 `savesubmission`（保存文件）与 `confirmsubmit`（最终提交），并有草稿保存不会自动最终提交的测试。本轮加强 UI 和模型约束：

- 上传界面的确认动作称为“保存文件”，说明保存后仍可修改、尚未最终提交。详情将草稿附件标为“已保存文件（草稿，尚未最终提交）”。
- “最终提交”先只读获取最新附件和平台声明，再显示居中的检查对话框；列出作业标题、附件数量和全部文件名。
- 必须勾选“我已核对全部文件，确认提交后不能再修改”。有平台声明时还必须另行勾选同意。没有附件时不能确认。长清单可滚动查看。
- 模型要求已准备当前作业的文件清单并收到明确确认；正式提交前再次只读核对文件名清单及可提交状态，有变化则要求重新检查。
- 保存新文件、切换／关闭作业详情会使旧确认失效；最终提交确认只消费一次。响应不确定时提示先刷新核对，不自动重复 POST。

验证筛选：`MoodleAssignmentTest`、`PhyVlabScreenModelTest`、`PhyVlabActivityStatusTest`、`PhyVlabSubmissionVisualTest`。包含草稿可修改、正式提交后锁定、未经确认不得提交、空附件／清单变化不得提交、平台声明和不重放写请求。

结果：29 项测试全部通过，`git diff --check` 通过。浅色／深色各有／无平台声明的 4 张图已检查，清单和勾选项可读；未勾选时确认按钮禁用。
