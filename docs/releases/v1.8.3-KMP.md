# 交大自由行 KMP 1.8.3-KMP

发布日期：2026-10-10

接入 CITEL 作业，支持作业聚合，适配 iPhone Duo / 横屏，并调整闲置后的自动刷新。

## 更新内容

- **CITEL 作业功能**：可单独配置CITEL平台账号，同步书面作业与编程练习；支持报告增删替换和代码提交。编程作业以评测通过（AC）视为完成，详情显示用例通过情况；可查看折扣倍率及开始、折扣、截止时间。
- **物理在线**：支持文件上传和提交。
- **作业聚合**：新安装默认把课程平台、物理在线和 CITEL 合为同一「作业」入口，也可在设置中分开。卡片区分来源和提交状态，三个平台分开同步；筛选条件按账号保存。
- **首页**：显示正在上课和即将开始的课程，以及临近截止的作业。数据变动弹窗按来源分区。
- **iPhone Duo 与横屏**：iPhone Duo 支持使用系统侧栏；普通 iPhone 横屏避开灵动岛，并调整横屏课表展示。
- **闲置后刷新**：iOS、Mac、Android 在后台停留至少 15 分钟后，回到前台才刷新一次。Windows 不以窗口聚焦触发；闲置 15 分钟后，下一次点到应用内容才刷新。
- **macOS 钥匙串**：登录凭据、缓存密钥、物理实验和 CITEL 账号合并为一条。升级后安装时，钥匙串输入密码提示减为一次，旧分条会迁入新条目。
- **邮箱附件**：支持查看和保存邮件附件。
- **修复完美校园Android版无法跳转**：更换跳转方式。
- **性能优化**：同步改为并行，减少同步报错提升加载速度。

CITEL 和物理实验需在设置中单独配置账号。物理在线同步需要校园网。

## 构建产物

| 文件 | 说明 |
| --- | --- |
| `BJTUSelfService-KMP-1.8.3-arm64-v8a.apk` | Android arm64-v8a 签名 Release APK，versionCode `26` |
| `BJTUSelfService-KMP-1.8.3-iOS-unsigned.ipa` | iOS arm64 未签名 IPA，构建号 `26`，需自行签名后侧载 |
| `BJTUselfServiceKMP-1.8.3.dmg` | Apple Silicon macOS 安装包 |
| `BJTUselfServiceKMP-1.8.3.msi` | Windows x64 安装包 |

## 安装注意事项

- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](docs/iOS-sign-guide.md)
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行 KMP.app`
- 近期版本的更新日志，参见[Release Notes](docs/releases)
