## 基线行为

- 单一接口：`https://aa.bjtu.edu.cn/examine/examplanstudent/stulist/`。
- 解析 `tbody > tr`；第 2–6 列依次为考试类型、课程名、时间与地点、考试状态、详情。
- 原版筛选项来自 `examType` 去重，并加“全部”；界面没有独立学期字段，迁移不能凭视觉把考试类型误写成学期。
- 汇总卡显示当前筛选下的数量；每张卡显示上述五类信息。
- 同步失败应继续显示当前账号旧缓存，不用空列表覆盖。

## 实现范围

1. 严格 HTML 解析与枚举错误，不把响应正文写入异常。
2. 复用登录后的 Cookie 会话；区分网络、会话失效和页面结构变化。
3. Repository 缓存优先并按账号原子替换 `exam_cache`。
4. 状态模型管理类型筛选、详情、刷新来源与失败反馈。
5. 登录后应用导航增加“考试安排”。

## Apple 布局

- iPhone：类型 chips 可换行；考试卡片保留关键信息，点击后以底部 sheet 展示完整详情。
- macOS：侧栏直达考试安排；主区使用考试列表和常驻详情，避免每张卡重复占用过多纵向空间。
- 刷新保留旧内容并显示线性进度；不使用无意义弹跳。
