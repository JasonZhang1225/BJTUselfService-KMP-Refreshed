# 交大自由行 KMP 1.7.9

发布日期：2026-09-26

本版 iOS 最低系统为 iOS 16。

## 新增

- 无。

## 优化

- 退出登录时同步清理学校登录状态和应用内网页数据。
- 桌面缓存加密保存，全量清除后退出并删除本机凭据。
- 成绩默认顺序与教务页面一致，调整排序选项。
- 首页加载周次时点选日期也有切换反馈。

## 修复

- 修复 iOS 重装后可能沿用旧登录凭据。
- 修复 macOS 打开成绩筛选时可能卡住。
- 改善 iOS 顶栏玻璃随滚动变化的效果。

## 构建产物

| 文件 | 说明 |
| --- | --- |
| `BJTUSelfService-KMP-1.7.9-arm64-v8a.apk` | Android arm64-v8a，versionCode `20`，由 CI 使用项目上传签名构建 |
| `BJTUSelfService-KMP-1.7.9-iOS-unsigned.ipa` | iOS arm64 未签名 IPA，需自行签名后侧载 |
| `BJTUselfServiceKMP-1.7.9.dmg` | Apple Silicon macOS 安装包，安装器数值版本 `1.7.9`，构建号 `20` |
| `BJTUselfServiceKMP-1.7.9.msi` | Windows x64 安装包，安装器数值版本 `1.7.9` |

## 安装注意事项

- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/blob/main/docs/iOS-sign-guide.md)
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行\ KMP.app`
- 近期版本的更新日志，参见[Release Notes](docs/releases)
