# 交大自由行 KMP 1.7.3-KMP-B

来源：GitHub Release 已删除。正文取自打 `v1.7.3-KMP-B` 时 `.github/workflows/kmp-package.yml` 的 `body`。

### 本版修复

- 教学周优先使用智慧教学 `getTimeList.weekCode`（与原版 1.7.0 一致），失败再回退教务 `room_view?zc=`
- 作业解析对齐 1.7.0 容错：空学期、单课/单类型 JSON 异常不再整批报「响应结构已变化」

### 安装说明

| 文件 | 说明 |
| --- | --- |
| `BJTUSelfService-KMP-*-debug.apk` | Android debug，包名 `team.bjtuss.bjtuselfservice.kmp` |
| `BJTUSelfService-KMP-*-iOS-unsigned.ipa` | iOS 未签名，需侧载自签 |
| `BJTUselfServiceKMP-*.dmg` | macOS Apple Silicon |
| `BJTUselfServiceKMP-*.msi` | Windows x64 系统级安装 |

Windows 覆盖安装：先完全退出应用，不要先卸载（卸载会清登录）。若安装器只出现「修复/卸载」，请用：

`msiexec /i 文件名.msi REINSTALL=ALL REINSTALLMODE=vomus`

### 已知限制

- 非正式商店签名 / 未公证；iOS 需自行签名侧载；Mac 版可能需执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行 KMP.app`
- 小组件、系统通知等仍延后
- Windows MSI 产品版本仍为 `1.7.3`，与上一版 ProductCode 相同，须按上面的覆盖方式换文件
