# M12：课程表体验整合（日期跳转 / 一周视图 / 系统日历）目标文档

> 状态：**已完成**（2026-08-11）。功能、编译、自动化门禁与用户实体触摸板/跨学期日期验收均已完成。
> 上游需求来源：用户 2026-08-09 提出课程表日期跳转、一周整合视图和日历功能；2026-08-10/11 进一步明确：入口放在顶栏同步胶囊旁，Apple 端直接创建系统日历，课程日历默认名为“本学期课表”/“选课课表”，考试必须逐场单条加入，禁止批量或合并导入。

## 1. 背景与现状

KMP 课表（M5-2）已支持「本学期课表 / 选课课表」切换与「全部 + 1–26 周」周选择，考试（M5-3）已支持列表与筛选，但仍有三个体验缺口：

| 缺口 | 现状 | 影响 |
|---|---|---|
| 只能按「第几周」选，不能按具体日期 | 课表数据本身不带日期，周→日期映射未接入 | 计划出门时无法快速看「9 月 15 日有没有课」 |
| 紧凑端只有单日视图 | 手机按「周一~周日」切换，看一周要多次点按 | 无法一眼扫视整周安排 |
| 课程表与考试都无法加入系统日历 | 课表和考试都只能在 App 内查看 | 无法在系统 Calendar 中做长期规划与提醒 |

M11 教室占用查询已验证 bksy `SemesterTranPage` 的 `hidJson` 周→日期映射，课表可直接复用。

## 2. 目标

把课程表从「按周浏览」升级为「按日期可查、整周可看、课程与考试可导出」：

- **M12a 日期跳转**：提供“前往日期”入口。概览表格只定位目标日期所在教学周，不保留“选中某一天”的视觉状态；列表模式同时定位目标周与当天课程。
- **M12b 课程浏览**：紧凑端提供带图标的“概览表格 / 列表”切换并默认进入概览；列表在周内横滑切日，概览使用完整 7 天 × 7 节表格并横滑切周。课程仅显示按课程号映射课程性质的配色块，点按色块再看详情。宽屏七日网格使用相同性质配色和图例，并提供左右按钮与 macOS 原生触摸板双指横滑切周；每个手指手势只翻一周，抬手后的惯性不翻页。切周时只有表格主体按方向做无回弹、可打断的翻页动画，工具栏保持固定。
- **M12c 系统日历**：课程可按周范围加入独立日历；同一上课时间写为每周重复系列，停课、单双周作为例外，以便系统日历批量修改后续课程。考试只允许当前这一场单条加入。Apple 端优先 EventKit，其他平台及 Apple 端均保留单独 `.ics` 兜底。

## 3. 子项范围

### M12a：课程表日期跳转

- 复用 M11 的 bksy `hidJson` 解析，分别建立本学期与选课学期的「日期 ↔ 教学周 + 星期几」映射。
- 课表页新增“前往日期”入口（日历弹层或日期选择器）。
- 概览表格选择日期后只呈现目标教学周，表格列头不高亮某一天；列表模式同时呈现该日期对应的课程。目标日期命中另一学期时，必须原子切换课表类型、学期校历、周次与日期；日期不属于两套已知校历时保持明确空态，不猜学期。
- 非教学周日期（假期、考试周）给出明确空态提示。

### M12b：手机列表与完整一周表格

- 紧凑端以带左侧图标的「概览表格 / 列表」切换两种视图，概览在左并作为默认；概览表格与桌面同构，为一屏放下的 7 天 × 7 节完整表格。
- 单元格不显示课程名/地点；有课时使用成绩页必修/限选/任选/体育/未知五色板。课程性质必须先按课程号查询培养方案映射，不能按课程名或哈希猜测；未知才显示灰色。
- 「全部教学周」是概览分页最左侧的独立第 0 页，紧邻第 1 周，不复用当前周页；该页同一时间格中的单双周/交替课程并排显示为半格，点按任一半格查看对应详情。
- 概览表格横滑切换全部/第 1～30 周；周数只在上方课表控制栏显示，表格标题栏不重复。标题栏左侧使用五个清晰的彩色胶囊展示必修/限选/任选/体育/未知图例，右侧固定“滑动切换周数”。列表横滑时只在当前周的七天内切日。
- 顶部日期使用“6月15日”中文月日，不再使用“6/15”；宽屏/macOS 七日网格列头也显示日期。
- 概览标题只显示课表名与“第 x 周”，小字显示“当前第 x 周”；列表标题在“第 x 周”后显示所选“x月x日”，小字显示“当前第 x 周，今天是 x月x日”。教学周选择弹层不再显示“全部位于第 1 周左侧”等实现说明。
- 宽屏/macOS 现有七日网格增强：列头显示对应日期，不只是「周一~周日」。

### M12c：加入系统日历

- 课程表页顶栏右上角在同步胶囊旁显示“添加到日历”（系统日历不可用的平台显示“导出”）。
- **课程**：当前课表类型按用户选择的教学周范围生成每周重复系列；停课周、单双周缺口写为例外；含课程名、时间、地点、教师。系统日历默认名：本学期课表 → “本学期课表”，选课课表 → “选课课表”。选课课表必须使用语义上的下一学期校历；未取得下一学期校历时禁用导出，绝不复用当前/旧学期日期。弹层标题为“导出本学期课表到日历”或“导出选课课表到日历”，不再展示重复规则实现说明；成功文案明确显示目标日历及新增/更新数量。
- **考试**：只在单场考试详情中显示“添加到日历”；每次仅写入当前这一场，默认日历名“考试安排”。确认弹层直接显示考试名称、时间、地点，不展示批量边界说明；成功文案为“已导入日历‘考试安排’，新增…，更新…”。不得提供“全部考试”、筛选结果批量或课程+考试合并导入，避免学校侧考试增删改滞后造成旧安排污染日历。
- **地点显示**：服务端原始地点字段不改写；课表详情、首页变化和日历导出统一按逗号分段后整体倒序，并以 `-` 连接，例如“海淀西校区，思源楼，SY101”显示/导出为“SY101-思源楼-海淀西校区”。首段不假定必须以“校区”结尾，“研究生唐山研究院”等同样按层级处理。
- Apple：iOS/macOS 通过 EventKit 创建或复用精确同名日历；首次请求系统日历权限。日程 notes 首行保存稳定标记，重复加入时更新原日程，不堆叠副本，也不删除用户日历中的其他日程。
- 兜底：共享层生成 RFC 5545 `.ics`。课程可生成当前周范围的文件；考试 `.ics` 仍只含当前这一场。Android 使用系统分享/保存，Apple 也保留“另存 .ics”。取消不显示红色错误。
- 与 M12a 的日期映射共用同一套周→日期数据。

## 4. 平台差异

| 平台 | M12a 日期跳转 | M12b 一周视图 | M12c 导出 |
|---|---|---|---|
| Android/iOS 紧凑 | Material 日期选择器 | 列表周内横滑；概览 7×7 表格 + 性质色块详情 + 全部页半格 + 横滑切周 | iOS EventKit；Android `.ics` 分享/保存；考试单条 |
| macOS 宽屏 | 日期选择器 | 七日网格列头加日期；性质色块+图例；左右按钮/触摸板横滑切周 | EventKit 创建独立日历与重复系列；`.ics` 兜底；考试单条 |
| 共享层 | 日期↔周映射为纯 Kotlin 状态逻辑 | 单日/一周状态与布局自适应 | 共用事件展开、考试宽容解析和 ICS 生成器 |

## 5. Apple 设计要求

- **响应**：点日期/切周/点导出立即反馈，不等网络；日期选择器打开即显示，不加载。
- **可打断**：日历弹层、周视图横滑均可中途抓取反向；导出进度可取消。
- **空间一致**：紧凑端日期不再占据大 banner，只在轻量控制栏中显示小日期按钮；日期弹层从该按钮打开。
- **克制弹性**：日期切换、周滑动保持可打断；概览表格标题栏保持固定图例和“滑动切换周数”，不重复动画周数；导出成功用轻量反馈。
- **反馈完整**：日期无课、导出中、导出成功/失败/取消各有明确状态。
- **排版可伸缩**：日期、课程名、地点在窄屏不截断关键信息；支持动态字体。

- [x] bksy `hidJson` 已在当前真实课表学期用于日期跳转和事件展开；无法映射的日期保持明确空态，不猜教学周。

## 8. 依赖与风险

- **依赖**：M5-2 课表数据与缓存；M5-3 考试数据与缓存；M11 bksy 日期映射。
- **风险**：课程/考试时间格式不规则 → 解析器必须宽容，不可解析的考试明确禁用加入；课程事件量大 → EventKit 需实测性能与稳定标记去重；考试增删改可能不同步 → 产品层强制单条加入，不实现批量删除或同步。
