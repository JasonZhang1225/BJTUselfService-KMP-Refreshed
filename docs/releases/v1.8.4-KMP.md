# 交大自由行 KMP 1.8.4-KMP

发布日期：2026-10-14

## 新增

- 新增物理演示实验，预约安排进入首页。
- iOS 和 Android 新增临近课程、今日课程、本周课表小组件。
- 新增第二节错峰上课时间，课表、首页、小组件和日历同步调整，可在设置中关闭。
- 校园卡与校园网缴费支持保存二维码、打开微信扫一扫和复制链接。

## 优化

- 统一课程表、首页、成绩和小组件的课程配色。
- 首页物理在线与 CITEL 日程可直接进入详情。
- 课件批量导出跳过未开放下载的文件并列出，放宽大文件等待时间。
- 减少同步期间滑动卡顿，合并旧版升级提示。

## 修复

- 修复 HyperOS 小窗中顶栏、底栏和弹窗被遮挡。
- 修复 iOS 弹窗关闭后立即重开无响应，改善筛选与日期弹层高度。

## 安装注意事项

- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](docs/iOS-sign-guide.md)
- iOS 小组件需要 iOS 17 及以上，签名时须保留 App 扩展（SideStore 选择“Keep App Extensions (Use Main Profile)”）。若小组件显示“无法读取课表”，说明签名工具没有保留 App Group，可换用保留扩展的方式重新签名。
- 荣耀手机请在桌面双指捏合 →「桌面卡片」→「经典小工具」中添加小组件，暂不支持荣耀「服务卡片」。
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行\ KMP.app`
- 近期版本的更新日志，参见[Release Notes](docs/releases)
