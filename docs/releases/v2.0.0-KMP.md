# 交大自由行 KMP 2.0.0-KMP

正式发布日期：待定

本版新增课程回放、双画面播放与视频下载合成，并改善下载恢复、首页数据变动和多平台实时活动。当前分支为 **2.0.0-Alpha（Build 45）**，本文是正式版发布说明草稿。

## 新增

- **课程回放**：在「应用 → 课程回放」选择课程、课节和录像画面，可预览后播放教师画面、屏幕/课件或其他可用画面。
- **双画面播放与全屏**：支持两路录像同步播放、选择声音、调整倍速和跳转；各平台播放器都可进入全屏，横向全屏时可并排观看两路画面。
- **回放下载与合成**：所选画面可分别保存为 MP4，也可将两路合成为左右并排的视频，声音取教师画面；合成提供高、中、低三档清晰度。
- **下载任务管理**：可查看下载、合成与保存进度，支持暂停、继续和自动重试；Android 和 Windows 会保留已下载的分片与保存位置，以便中断后恢复。
- **课件备用保存**：对网页未提供直接下载的课件，尝试通过备用方式保存原文件；批量导出会说明无法取得或超出限制的文件。

## 优化

- **边下载边合成**：Android 和 Windows 下载两路录像时即可开始合成，支持使用设备提供的硬件加速。Windows 自动优先尝试 NVIDIA，再尝试其他可用显卡，包括 Intel 核显和 AMD；硬件管线不可用时使用兼容模式。
- **Windows 合成设备显示**：下载任务中显示当前使用的显卡及硬件加速状态，或显示 CPU 兼容模式；设备发生切换时同步更新。
- **下载进度与剩余时间**：速度按实际接收的数据计算，剩余时间使用平滑估算，并考虑下载与合成两个阶段；网络中断后按 2、4、8 秒间隔自动重试。
- **首页布局**：「数据变动」移到临近截止提醒下方、日程窗格上方；没有内容的区域不会留下多余空白。
- **作业信息**：统一作业卡片的开始时间、截止时间和评分显示；CITEL 折扣时间延后及完成状态向好的变化会标绿。
- **iOS 回放导航**：回放详情改为普通二级页面，避免误触关闭弹层；下载过程尽量复用系统提供的后台进度活动。
- **macOS 启动器**：打包时支持使用较新的 macOS SDK 编译原生启动器，改善新系统上的兼容性。

## 修复

- 修复 Android 回放预览黑屏、播放异常、下载速度显示偏差，以及下载中断后难以恢复的问题。
- 修复 Android 下载通知反复闪烁和部分情况下前台服务启动超时导致退出；页面或会话刷新不再主动丢弃正在执行的下载任务。
- 修复 Windows 双画面合成缺少教师音轨的问题，并改善任务记录、保存位置及合成进程的恢复与清理。
- 修复 iOS 下载进度活动重复出现或频繁闪烁，并保留上课实时活动；修复部分灵动岛展开内容被裁切及课前、上课中高度变化。
- 修复首页临近截止提醒中的已提交作业判断，以及 CITEL 编程题评分和作业完成状态的显示问题。
- 修复更新检查可能受历史最高版本缓存影响而错过后续更新的问题。

## 已知问题

- **Android 性能与兼容性**：本轮新增的整理和编解码兼容改动尚待平板及其他芯片设备实测；此前整节录像的下载与合成约需 16 分钟，实际时间受设备和网络影响。
- **Windows 显卡**：NVIDIA 和 AMD 已进行本机测试，Intel 核显的自动选择和回退仅经过模拟测试，仍需 Intel 设备实测。CPU 兼容模式可用，但完整课程的速度尚未验证。
- **暂停与后台**：Windows 在暂停或中断合成后保留已下载分片，但继续时需要从头合成；关闭窗口是否继续任务取决于是否启用了关闭到托盘。iOS 的后台合成受系统版本和后台时间限制，进程重启后的任务恢复能力与 Android、Windows 不同。
- **录像清晰度**：学校目前提供的每路录像只有一个源清晰度；高、中、低选项调整的是合成视频的输出分辨率和码率，不会切换较低清晰度的下载源。

## 安装注意事项

- iOS 主程序和小组件最低需要 iOS 18；未签名 IPA 需自行签名侧载，参考 [iOS 自签与安装指南](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/blob/main/docs/iOS-sign-guide.md)，签名时须保留 App 扩展。
- 应用内版本显示为 `2.0.0-Alpha`；iOS 主程序、小组件和桌面安装器的系统版本使用纯数字 `2.0.0`，构建号为 `45`。
- Windows 安装包使用项目现有升级标识，安装时可能替换已安装版本。
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行\ KMP.app`。
- 近期版本的更新日志，参见 [Release Notes](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/tree/main/docs/releases)。
