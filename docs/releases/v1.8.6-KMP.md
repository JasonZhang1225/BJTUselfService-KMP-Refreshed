# 交大自由行 KMP 1.8.6-KMP

发布日期：2026-10-23

本版本带来多项新增、优化和修复。新增图书馆借阅、灵动岛与实时活动、作业搜索，以及本地 AI 助手和 ChatGPT 插件；移除验证码识别模型，安装包明显变小。

## 新增

- **双更新源**：支持通过 GitHub 或 Gitee 检查更新、下载安装包。在设置中可选择 GitHub、Gitee 或自动选择；自动模式下，GitHub 连接失败或请求超过 5 秒时切换至 Gitee。
- **图书馆**：可以查看借阅的书并续借，入口在应用页。
- **底栏入口调整**：添加到底栏的应用仍会保留在应用页，两边都能打开。“设置”固定排在应用页最后。
- **灵动岛与实时活动**：
  - iOS 上日程可以显示在灵动岛和实时活动里，并支持 Apple Watch 智能叠放。
  - Android 16 及以上支持课程实时动态（Live Updates），在 HyperOS 等系统上会以灵动岛样式显示。
  - 课前会准点出现，可以在「正在上课」或「即将上课」卡片上调整出现时间。
- **作业搜索**：在作业页可以搜索全部作业，不受筛选条件限制。
- **作业详情导出 Markdown**：作业、物理在线、CITEL 的详情页可以“复制为 Markdown”，也可以“保存为 Markdown”到本地文件。
- **教学楼**：教室占用会突出显示当前节次，并列出空闲教室。
- **本地 AI 助手**：可以接入 Codex、Claude Code、WorkBuddy 等工具，采用 Skill + CLI 架构。
- **ChatGPT 插件**：借助付费 ChatGPT 账号的 Sites 功能创建私人插件，即可用 ChatGPT 远程查询课表、成绩、作业等信息。
  - 数据由你自己的设备上报：手机每次刷新时上报；电脑可以在后台定时同步，并接收 ChatGPT 发来的刷新请求。
  - 手机和电脑可以同时连接，私人 Site 页面会分别显示每台设备最近一次联系的时间和它上报的数据，可以单独撤销某台设备。
  - 电脑端可以关闭「后台定时同步」，关闭后和手机一样，只在应用内刷新或点「立即同步」时上传。
  - 插件开关默认开启，但只有完成配对后才会上传数据。
- **电脑端开机启动**：支持开机启动、后台运行和静默启动，在应用的「设置」页管理。Windows 点关闭按钮时可收进托盘，点最小化按钮为普通最小化。

## 优化

- **安装包瘦身**：移除了本地验证码识别模型，安装包体积大幅缩小。登录时如果小概率遇到字母验证码，需要手动输入。
- **首页截止提醒**：「48 小时内截止」的提醒现在也包括未完成的物理在线和 CITEL 作业。
- **下一节课**：课间、晚饭时间以及当天第一节课前，首页会高亮当天的下一节课。
- **CITEL 编程题题面**：去掉题面里多余的空行；题面默认收起，点「点击查看题目」再展开。
- **版本说明**：首次进入 1.8.6 会显示一次版本说明；Android 首次进入主界面时会说明用途并申请通知权限。

## 修复

- 教务系统宕机或连不上时，自动登录不再闪退，会直接进入主界面。
- 降低覆盖安装或启动异常时本地数据被清空、已保存账号丢失的风险。
- 修复 iOS 无法打开作业上传的文件选择器，并统一了三个上传页的行为。
- 修复 iOS 关闭弹层后部分入口点击无反应。
- 修复 iOS 成绩变动弹窗标题栏按钮被遮挡、留白过大。
- 数据变动弹窗中，作业、物理在线和 CITEL 从“未完成”变为“已完成”等利好变动会标绿。
- 修复 Android 原生页面之间跳转时登录状态丢失。
- 修复 Android 课表小组件在部分桌面上排版异常。

## 已知问题

- **字母验证码**：需要验证码时改为手动输入，这条路径尚未在学校服务器上实际触发验证。
- **未经实机验证**：Windows 托盘在多屏混合缩放下的位置等，尚未在真机上完整验证。如遇异常请反馈，欢迎你的issue。

## 安装注意事项

- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/blob/main/docs/iOS-sign-guide.md)
- iOS App 与小组件**最低要求提高到 iOS 18**（1.8.5 为 App iOS 16、小组件 iOS 17），iOS 16、17 设备请继续使用 1.8.5，签名时须保留 App 扩展（SideStore 选择“Keep App Extensions (Use Main Profile)”）。
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行\ KMP.app`
- 近期版本的更新日志，参见 [Release Notes](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/tree/main/docs/releases)
