## 6. 本轮 Computer Use 盘点边界

本轮按以下顺序完成：

1. 首页正常、加载、刷新、状态卡和 DDL。
2. 应用页 7 个入口及安全可查看的二级页。
3. 设置页所有条目、弹窗和切换前状态。
4. 返回、底部导航、页面切换和滚动行为。
5. 1.7.0 专项中，成绩自选、周数控制、作业附件入口、课件展开和教室两级列表已实机观察；小组件、同名作业同步、壁纸/玻璃态和教室安排弹层保留明确未验证记录。

提交作业、充值、发送、订阅、清数据、退出账号等会改变外部或重要本地状态的动作不在默认盘点权限内。

脱敏视觉文件及其限制见 `docs/migration/visual-baseline/README.md`。WebView 和 Dialog 背景不能仅依赖 Android 可访问性文字框自动遮挡。
