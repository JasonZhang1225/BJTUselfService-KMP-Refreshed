# 交大自由行 KMP 1.7.6-KMP

## 新增

- 无。

## 优化

- 首页日程支持横滑切周，简化加载提示，支持非教学周。
- 物理在线统一功能开关，详情先显示缓存再更新。
- 改善作业上传失败提示与登录过期后的恢复。

## 修复

- 修复首页切周时卡片高度跳动、周次被刷新覆盖。
- 修复课件刷新后仍显示旧目录。
- 恢复桌面端物理在线入口，改善 Windows 安装与触控板翻页。

## 版本

- Android `1.7.6-KMP`（versionCode `17`，默认 `arm64-v8a`）
- iOS `1.7.6-KMP`（Build `17`，未签名 IPA）
- macOS / Windows 安装器数值版本 `1.7.6`

## 安装说明

| 文件 | 说明 |
| --- | --- |
| `BJTUSelfService-KMP-*-arm64-v8a.apk` | Android arm64-v8a，包名 `team.bjtuss.bjtuselfservice.kmp`。本地与 GitHub Actions 使用同一上传签名，可覆盖安装 |
| `BJTUSelfService-KMP-*-iOS-unsigned.ipa` | iOS 未签名，需侧载自签 |
| `BJTUselfServiceKMP-*.dmg` | macOS Apple Silicon |
| `BJTUselfServiceKMP-*.msi` | Windows x64 系统级安装 |

Windows 覆盖安装：先完全退出应用，不要先卸载（卸载会清登录）。若安装器只出现「修复/卸载」，请用：

`msiexec /i 文件名.msi REINSTALL=ALL REINSTALLMODE=vomus`

## 已知问题

- 非正式商店签名 / 未公证；iOS unsigned IPA 需自行签名侧载；Mac 版可能需执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行\ KMP.app`
- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/blob/main/docs/iOS-sign-guide.md)
- 物理在线的自动同步依赖校园网，离开校园网时只能读取已有缓存；真实文件提交仍需在可编辑作业上继续验收。
- 邮箱写信/回复已完成协议和界面接入，但真实发送、删除、移动、转发及附件写操作仍需单独验收。
- 小组件、系统通知等仍延后；Android 默认 APK 仅支持 `arm64-v8a`。
- Windows MSI 使用同一 UpgradeCode，支持同为 `1.7.6` 数值版本的安装包覆盖升级；建议直接运行 MSI，不要先卸载。
