## 安全与登录（由GLM5.3调研安全缺陷，GPT 5.6 Sol 和 GPT 6 Sol执行修复和验证）

- 登出时请求学校 CAS 退出，并清理移动端 WebView 数据。放弃手动验证码也走同一清理，完成前不能开始下一次登录。
- 桌面缓存改为加密保存。设置里的全量清除会清空数据库、截断 WAL、删掉本机凭据并退出。
- iOS 缺少本次安装的“记住密码”标记时，不再沿用卸载后残留的 Keychain 凭据。最低系统改为 iOS 16.0。
- macOS 已在正式安装上验收全量清理：清理后立即回到登录页，重启不会自动登录。iPhone 卸载重装、带登录态的网页登出，以及 Android 真机验证码仍待设备验收。

## 成绩、课表与首页日程

- 成绩默认顺序改回教务网页当次抓到的行序。筛选里「正序」在前、「逆序」在后，选定方向后关闭面板。
- macOS 课表的触控板翻页不再从界面线程同步进入系统辅助功能，避免打开成绩筛选时卡住。
- 首页在「日程加载中」、教学周数还没显示时，iOS 和 Android 点选日期也会播放内容切换。左右滑动切周仍等周数确认后再启用，避免启动时被带到错误的一周。

## iOS 标题栏

- 优化液态玻璃效果。标题栏玻璃跟随真实滚动偏移变化。首页第一张高卡片上滑后即有进度；课表、课件、教室详情和占用详情仍保持静态栏。

## 已知限制

- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/blob/main/docs/iOS-sign-guide.md)
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在系统安全设置中确认。
- 物理在线、旧教学平台作业和课件仍受学校网络和原站状态影响。提交作业、发送邮件等会改变远端数据的操作需要单独确认。
- Android 本版默认提供 `arm64-v8a` 构建。小组件和系统通知不在本版本范围内。
