# 交大自由行 KMP 1.8.1

发布日期：2026-10-05

新增考试与物理实验课表显示，并优化同步、日历导入和 iOS 界面体验。

## 更新内容

- **课程表**：加入考试和物理实验，时间重叠时并排显示；导出日历可选择包含物理实验。
- **物理实验同步**：在“更多”中配置实验系统账号，连接校园网后同步已选实验，校外可查看缓存。
- **日历导入**：修正单双周课程的日期安排，优化重复导入时的日程更新。
- **同步优化**：核心数据默认自动同步，修复部分作业获取失败和课表加载等待问题。
- **iOS 界面**：修复顶栏模糊渐显、页面切换时效果串用及实验设置页底部显示问题。
- **其他改进**：优化深浅色显示与账号安全处理。

物理实验和物理在线同步需要校园网。

## 构建产物

| 文件 | 说明 |
| --- | --- |
| `BJTUSelfService-KMP-1.8.1-arm64-v8a.apk` | Android arm64-v8a，versionCode `22`，由 CI 使用项目上传签名构建 |
| `BJTUSelfService-KMP-1.8.1-iOS-unsigned.ipa` | iOS arm64 未签名 IPA，需自行签名后侧载 |
| `BJTUselfServiceKMP-1.8.1.dmg` | Apple Silicon macOS 安装包，安装器数值版本 `1.8.1`，构建号 `22` |
| `BJTUselfServiceKMP-1.8.1.msi` | Windows x64 安装包，安装器数值版本 `1.8.1` |

## 安装注意事项

- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/blob/main/docs/iOS-sign-guide.md)
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行 KMP.app`
- 近期版本的更新日志，参见[Release Notes](docs/releases)
