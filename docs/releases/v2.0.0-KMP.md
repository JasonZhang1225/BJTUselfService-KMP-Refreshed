# 交大自由行 KMP 2.0.0-KMP

正式发布日期：待定

当前为 2.0.0-Alpha / Build 45，以下为正式版发布说明草稿，内容更新至当前 main。

## 新增

- **课程回放**：在「应用 → 课程回放」选择课程、课节和录像画面，观看教师、屏幕或课件画面。
- **双画面播放**：支持两路录像同步播放、选择声音、调整倍速、跳转与全屏，横屏可并排观看。
- **电脑端录像下载**：Windows 和 macOS 可分别保存画面，或合成为左右并排的 MP4，支持高、中、低三档输出清晰度。Android 和 iOS 仅提供在线播放。
- **下载任务管理**：电脑端可查看下载、合成、保存进度，支持暂停、继续、自动重试和中断后恢复；已保存文件可打开或定位。
- **课件备用保存**：对未提供直接下载的课件尝试备用保存，批量导出列出无法取得的文件。
- **作业忽略**：课程平台、物理在线和 CITEL 的未提交作业可长按、右键、手机左滑或在详情中忽略，收进列表末尾的「已忽略」分组；可撤销，按账号保存在本机，不改变学校提交状态。
- **CITEL 折扣提醒**：首页单独提醒未来 48 小时内即将结束折扣的未完成作业；忽略的作业不再进入首页临近提醒。
- **更新日志**：在「应用 → 设置」后增加独立入口，可按版本离线查看新增、优化和修复。

## 优化

- **电脑端边下载边合成**：Windows 和 macOS 可在下载过程中开始合成，减少等待；Windows 显示当前合成设备或兼容模式。
- **macOS 合成提速**：改善长录像合成速度，本机整节测试由约 20.5 分钟缩短到约 5.7 分钟，实际用时随设备和课程变化。
- **进度与剩余时间**：下载速度与剩余时间更稳定，同时考虑下载和合成阶段，网络短暂中断后自动重试。
- **首页布局**：数据变动移到截止提醒下方、日程上方，没有内容时不留多余空白。
- **作业阅读**：统一开始、截止和评分信息，保留作业要求中的换行、列表、加粗与链接；完成状态向好及 CITEL 折扣延期标绿。
- **课件导出**：改善大文件保存、文件夹导出和进度显示，取消前提示确认。
- **iOS 回放导航**：详情使用独立页面，减少误触关闭；改善灵动岛与上课实时活动显示。
- **历史更新说明**：统一使用新增、优化、修复三个板块，突出实际使用变化。

## 修复

- 修复 Android 回放预览黑屏与播放异常。
- 修复电脑端下载任务恢复、保存位置和文件清理异常，避免合成失败后仍显示完成。
- 修复 Windows 双画面合成缺少教师声音，以及合成尾部画面处理异常。
- 修复移动端升级后遗留的录像下载任务仍显示可操作的问题。
- 修复部分 iOS 灵动岛内容被裁切和课前、上课中高度变化异常。
- 修复首页已提交作业的提醒判断、CITEL 编程题评分和完成状态显示。
- 修复作业忽略后的卡片背景、左滑返回后重复忽略等问题，支持 6 秒内撤销。
- 修复切换页面后作业本地标记可能保存失败，以及成绩课程性质筛选按钮布局不稳定。
- 修复更新检查受旧版本缓存影响而错过更新的问题。

## 已知问题

- Windows 的 Intel 核显自动选择仍需设备实测；兼容模式完整课程速度尚未验证。
- 暂停或中断合成后，已下载内容可保留，但继续时可能需要重新合成；关闭窗口后是否继续取决于后台或托盘设置。
- 学校每路录像目前只有一种源清晰度；高、中、低仅调整合成结果，不减少源录像下载量。
- Android 和 iOS 仅在线播放，不提供录像下载或合成。

## 安装注意事项

- iOS 主程序和小组件最低需要 iOS 18；未签名 IPA 需自行签名侧载，参考 [iOS 自签与安装指南](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/blob/main/docs/iOS-sign-guide.md)，签名时须保留 App 扩展。
- 应用内版本显示为 `2.0.0-Alpha`；iOS 主程序、小组件和桌面安装器的系统版本使用纯数字 `2.0.0`，构建号为 `45`。
- Windows 安装包使用项目现有升级标识，安装时可能替换已安装版本。
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行\ KMP.app`。
- 近期版本的更新日志，参见 [Release Notes](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/tree/main/docs/releases)。
