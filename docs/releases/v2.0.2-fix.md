# 交大自由行 KMP 2.0.2-fix

正式发布日期：2026.11.23

上次修复后，证书修复有bug，本版修复


## 新增

- 无。

## 优化

- 无。

## 修复

- **修复因学校缺失中间证书导致的无法登录与同步问题，以及2.0.1修复时的Bug。**：学校于 2026-11-17 换发 `*.bjtu.edu.cn` 新证书（由 `GeoTrust G2 TLS CN RSA4096 SHA256 2022 CA1` 签发），但 `mis.bjtu.edu.cn` 与 `mail.bjtu.edu.cn` 部署时只下发了叶子证书、漏发中间证书；浏览器与 iOS 会通过证书 AIA 自动补链，而 Android（OkHttp）与电脑端（macOS/Windows JVM CIO）默认不做 AIA 补链，导致 PKIX 证书链校验失败、登录卡在跳转 MIS 一环且无法同步首页账户状态与邮件。现已升级为三层安全自动补链（内置官方中间证书与被动缓存 + 同校公开 HTTPS 节点自动学习新中间证书 + 桌面端受限 AIA 动态拉取补链），并继续交由系统默认信任锚（`DigiCert Global Root G2`）完成完整证书链与域名校验，不放宽任何 TLS 安全校验。

## 安装注意事项

- iOS 主程序和小组件最低需要 iOS 18；未签名 IPA 需自行签名侧载，参考 [iOS 自签与安装指南](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/blob/main/docs/iOS-sign-guide.md)，签名时须保留 App 扩展。
- 应用内版本显示为 `2.0.2-Alpha-fix`；iOS 主程序、小组件和桌面安装器的系统版本使用纯数字 `2.0.2`，构建号为 `47`。
- Windows 安装包使用项目现有升级标识，安装时可能替换已安装版本。
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行\ KMP.app`。
- 近期版本的更新日志，参见 [Release Notes](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/tree/main/docs/releases)。
