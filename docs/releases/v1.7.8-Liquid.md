# 交大自由行 KMP 1.7.8-Liquid

## 新增

- iOS 使用原生底栏、导航栏、日期选择器和弹层，支持液态玻璃效果。

## 优化

- 统一 iOS 深色模式、详情页与筛选弹层的显示和关闭体验。
- 教学周之间的假期统一显示为非教学周。
- 精简同步状态面板，改善手机上的显示。

## 修复

- 修复课表切换、跳周时闪烁。
- 修复长时间闲置后登录失效提示不准确。
- 修复作业提示遮挡卡片、长详情底部操作显示不全。

## 构建产物

| 文件 | 说明 |
| --- | --- |
| `BJTUSelfService-KMP-1.7.8-Liquid-arm64-v8a.apk` | Android arm64-v8a，versionCode `19`，由 CI 使用项目上传签名构建 |
| `BJTUSelfService-KMP-1.7.8-Liquid-iOS-unsigned.ipa` | iOS arm64 未签名 IPA，需自行签名后侧载 |
| `BJTUselfServiceKMP-1.7.8-Liquid.dmg` | Apple Silicon macOS 安装包，安装器数值版本 `1.7.8` |
| `BJTUselfServiceKMP-1.7.8-Liquid.msi` | Windows x64 安装包，安装器数值版本 `1.7.8` |

## 安装注意事项

- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/blob/main/docs/iOS-sign-guide.md)
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行\ KMP.app`
- 近期版本的更新日志，参见[Release Notes](docs/releases)
