# 交大自由行 KMP 1.7.4-KMP

来源：GitHub Release 已删除。正文取自 `f7325ba`（docs: 更新 1.7.4-KMP 发布说明）写入工作流的 `body`。

### 本版更新

- 新增物理在线：复用 App 内 CAS/Moodle 会话读取课程、作业安排、提交状态、批改信息、评语和已提交文件。
- 物理在线作业的开放/截止时间进入首页安排；恰好在次日 `00:00` 截止的作业，首页按前一天标记截止。
- 物理在线增加按学号隔离的本地缓存。校园网或认证不可达时继续显示只读缓存，并明确显示“同步失败·正显示缓存”、失败原因和缓存创建时间。
- 首页部分同步失败可查看失败模块并主动重试；首页刷新、失败重试和进入物理在线页不会重复触发同一轮自动同步，打开/退出作业详情也不会清掉失败状态。
- 移动端物理在线作业详情改为原生二级页面，桌面端保留底部详情弹窗；窄屏布局增加自适应边距和安排控件换行。
- 保留 1.7.3-KMP-B 的教学周 `getTimeList.weekCode` 优先与作业解析容错，并统一版本标识为 `1.7.4-KMP`。

### 安装说明

| 文件 | 说明 |
| --- | --- |
| `BJTUSelfService-KMP-*-debug.apk` | Android debug，包名 `team.bjtuss.bjtuselfservice.kmp` |
| `BJTUSelfService-KMP-*-iOS-unsigned.ipa` | iOS 未签名，需侧载自签 |
| `BJTUselfServiceKMP-*.dmg` | macOS Apple Silicon |
| `BJTUselfServiceKMP-*.msi` | Windows x64 系统级安装 |

Windows 覆盖安装：先完全退出应用，不要先卸载（卸载会清登录）。若安装器只出现「修复/卸载」，请用：

`msiexec /i 文件名.msi REINSTALL=ALL REINSTALLMODE=vomus`

### 已知限制

- 非正式商店签名 / 未公证；iOS unsigned IPA 需自行签名侧载；Mac 版可能需执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行 KMP.app`
- 物理在线的自动同步依赖校园网，离开校园网时只能读取已有缓存；真实文件提交仍需在可编辑作业上继续验收。
- 小组件、系统通知等仍延后
- Windows MSI 使用 `1.7.4` 产品版本并沿用升级码；建议直接运行 MSI 覆盖升级，不要先卸载。
