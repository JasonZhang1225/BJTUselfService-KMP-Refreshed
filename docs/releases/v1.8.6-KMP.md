# 交大自由行 KMP 1.8.6-KMP

发布日期：2026-10-23

本版本带来多项新增、优化和修复。新增图书馆借阅、灵动岛与实时活动、作业搜索，以及本地 AI 助手和 ChatGPT 插件；移除验证码识别模型，安装包明显变小。

## 新增

- **双更新源**：设置中可选择 GitHub、Gitee 或自动选择；自动模式下连接 GitHub 失败或超过 5 秒时切换至 Gitee。
- **图书馆**：支持查看借阅与续借，入口在应用页。
- **灵动岛与实时活动**：iOS 日程支持灵动岛、实时活动与 Apple Watch 智能叠放；Android 16 及以上支持课程实时动态，可调整课前提醒时间。
- **作业搜索与导出**：搜索全部作业，不受列表筛选限制；课程平台、物理在线和 CITEL 详情可复制或保存为 Markdown。
- **教室查询**：突出当前节次，列出空闲教室。
- **AI 助手与 ChatGPT 插件**：支持本地 AI 工具查询，也可配对私人 ChatGPT 插件远程查询课表、成绩和作业。手机与电脑可同时连接，未配对时不会上传。
- **电脑端开机启动**：支持开机启动、后台运行和静默启动；Windows 关闭窗口可收进托盘。

## 优化

- **安装包瘦身**：移除验证码识别模型，需要验证码时手动输入。
- **应用入口**：已加到底栏的功能仍保留在应用页，设置排在其他功能之后。
- **首页提醒**：48 小时截止提醒加入未完成的物理在线和 CITEL 作业，课间及当天首课前高亮下一节课。
- **CITEL 题面**：减少空行，默认收起，点击后展开。
- **远程同步**：私人插件分别显示每台设备的联系与数据时间，可单独撤销设备；电脑可关闭后台定时同步，改为手动刷新时上传。
- **首次使用说明**：升级显示一次版本说明，Android 说明通知用途后申请权限。

## 修复

- 修复教务系统不可达时自动登录闪退，进入主界面后仍可查看已有缓存。
- 降低覆盖安装或启动异常时本地数据被清空、账号丢失的风险。
- 修复 iOS 作业上传无法打开文件选择器、关闭弹层后部分入口无响应，以及成绩变动弹窗按钮遮挡。
- 作业完成等向好变化在数据变动弹窗中标绿。
- 修复 Android 页面跳转后登录状态丢失，以及部分桌面课表小组件排版异常。

## 已知问题

- **字母验证码**：需要验证码时改为手动输入，这条路径尚未在学校服务器上实际触发验证。
- **未经实机验证**：Windows 托盘在多屏混合缩放下的位置等，尚未在真机上完整验证。如遇异常请反馈，欢迎你的issue。

## 安装注意事项

- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/blob/main/docs/iOS-sign-guide.md)
- iOS App 与小组件**最低要求提高到 iOS 18**（1.8.5 为 App iOS 16、小组件 iOS 17），iOS 16、17 设备请继续使用 1.8.5，签名时须保留 App 扩展（SideStore 选择“Keep App Extensions (Use Main Profile)”）。
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行\ KMP.app`
- 近期版本的更新日志，参见 [Release Notes](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/tree/main/docs/releases)
