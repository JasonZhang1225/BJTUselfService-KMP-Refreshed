# 交大自由行 KMP 1.8.0

发布日期：2026-09-29

## 新增

- 作业筛选新增“隐藏已提交”，按账号记住筛选条件。

## 优化

- 首页日程按作业提交情况显示颜色，包含物理在线。

## 修复

- 修复假期首页一直停留在“日程加载中”。
- 修复校历未取得时无法重试、自动定位到错误周次。
- 修复 iOS 首页顶栏玻璃效果不随滚动更新。

## 构建产物

| 文件 | 说明 |
| --- | --- |
| `BJTUSelfService-KMP-1.8.0-arm64-v8a.apk` | Android arm64-v8a，versionCode `21`，由 CI 使用项目上传签名构建 |
| `BJTUSelfService-KMP-1.8.0-iOS-unsigned.ipa` | iOS arm64 未签名 IPA，需自行签名后侧载 |
| `BJTUselfServiceKMP-1.8.0.dmg` | Apple Silicon macOS 安装包，安装器数值版本 `1.8.0`，构建号 `21` |
| `BJTUselfServiceKMP-1.8.0.msi` | Windows x64 安装包，安装器数值版本 `1.8.0` |

## 安装注意事项

- iOS unsigned IPA 需自行签名侧载，参考教程：[iOS 自签与安装指南](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/blob/main/docs/iOS-sign-guide.md)
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行\ KMP.app`
- 近期版本的更新日志，参见[Release Notes](docs/releases)
