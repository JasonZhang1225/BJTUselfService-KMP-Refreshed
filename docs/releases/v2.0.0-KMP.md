# 交大自由行 KMP 2.0.0-KMP

正式发布日期：待定

当前为 2.0.0-Alpha / Build 45，以下为正式版发布说明草稿，内容更新至当前 main，与 1.8.6 相比。

本版本新增课程回放：手机和电脑都能在线观看录像，电脑端还能下载、合成录像。作业可以忽略，筛选改为按截止日期和提交状态分别选择。另有 CITEL 折扣提醒和应用内更新日志。

## 新增

- **课程回放**：在「应用 → 课程回放」选择课程和课节，观看教师、屏幕或课件画面；可两路同步播放，选择声音、调整倍速、跳转和全屏，横屏并排观看。Windows 和 macOS 还可下载录像，单独保存或合成为左右并排的 MP4（高、中、低三档清晰度），下载可暂停、继续，中断后恢复。Android 和 iOS 仅在线播放。
- **作业忽略**：课程平台、物理在线和 CITEL 的未提交作业，可长按、右键、手机左滑或在详情中忽略，收进列表末尾的「已忽略」分组，可撤销。忽略按账号保存在本机，不改变学校的提交状态，也不再出现在首页截止提醒里。
- **作业筛选**：截止日期分为全部、未过期和指定日期三档，指定日期用系统日期选择器；提交状态单独切换全部或未提交。升级后保留原来的筛选设置。
- **课件流式导出**：课件边下载边保存，显示已下载大小和进度；批量与文件夹导出显示整体进度，取消前确认。
- **CITEL 折扣提醒**：首页单独提醒未来 48 小时内结束折扣的未完成作业。
- **更新日志**：「应用」页新增入口，可按版本离线查看新增、优化和修复。

## 优化

- **首页**：数据变动移到截止提醒下方、日程上方，没有内容时不留空白。
- **作业详情**：开始、截止和评分信息格式统一，CITEL 编程题没有分值时显示「暂无」；作业要求保留换行、列表、加粗与链接；零点截止显示为前一天 24:00；CITEL 评测由未做或错误变为通过、折扣时间延后也标绿。
- **课件下载**：没有直接下载链接的课件也会尝试保存，批量导出列出取不到的文件。
- **弹层**：作业筛选、考试筛选、考试详情和添加到日历按内容高度展开，不再铺满全屏。

## 修复

- 修复首页截止提醒把已有提交记录的课程平台作业算作未提交。
- 修复 iOS 灵动岛展开时文字被裁切、课前与上课中高度不一致。
- 修复超大体积的课件无法稳定正常下载。
- 修复 Android 导出整门课或文件夹时失败。
- 修复成绩课程性质筛选按钮在勾选、取消时宽度变化导致位置跳动。
- 修复更新检查受旧缓存影响而错过新版本。

## 已知问题

- Windows 的 Intel 核显自动选择仍需设备实测；兼容模式完整课程速度尚未验证。
- 暂停或中断合成后，已下载内容可保留，但继续时可能需要重新合成；关闭窗口后是否继续取决于后台或托盘设置。
- 学校每路录像目前只有一种源清晰度；高、中、低仅调整合成结果，不减少源录像下载量。
- Android 和 iOS 仅在线播放，不提供录像下载或合成。

## 安装注意事项

- iOS 主程序和小组件最低需要 iOS 18；未签名 IPA 需自行签名侧载，参考 [iOS 自签与安装指南](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/blob/main/docs/iOS-sign-guide.md)，签名时须保留 App 扩展。
- 应用内版本显示为 `2.0.0-Alpha`；iOS 主程序、小组件和桌面安装器的系统版本使用纯数字 `2.0.0`，构建号为 `45`。
- Windows 安装包使用项目现有升级标识，安装时可能替换已安装版本。
- macOS 安装包未进行 Developer ID 公证，首次打开可能需要在终端执行 `sudo xattr -r -d com.apple.quarantine /Applications/交大自由行\ KMP.app`。
- 近期版本的更新日志，参见 [Release Notes](https://github.com/JasonZhang1225/BJTUselfService-KMP-Refreshed/tree/main/docs/releases)。
