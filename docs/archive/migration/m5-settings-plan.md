# M5 设置切片

日期：2026-07-30  
基线：官方 `v1.7.0@419313d` 隔离源码、发布 APK 与 M0 脱敏行为盘点  
修改边界：仅 `multiplatform/` 与迁移文档；冻结 Android 工程只读

## 行为基线

原 Android 设置页包含账号、版本/更新、清除本地数据、GitHub、浅色/深色/跟随系统、动态配色、四项自动同步、更新提示、退出登录，以及 v1.7.0 的壁纸/Haze 入口。Apple 首版不照搬 Android APK 更新、Material You 或仅有外观但没有行为的开关。

## 本次实现

- 登录后应用壳新增第八个入口“设置”。
- `AppThemeOption` 支持“跟随系统 / 浅色 / 深色”，复用 SQLDelight 全局普通设置；保存成功才发布新状态，失败保留旧主题并就地提示。
- `App` 在根 `MaterialTheme` 读取主题偏好，因此切换会立即作用于登录页和全部业务页面，重启后仍可恢复。
- 显示当前账号、运行平台、KMP 迁移构建说明和 `v1.7.0` 功能对齐基线；GitHub 使用平台外部浏览器能力打开。
- “清除离线缓存”只清除当前账号的成绩、课程表、考试、作业、课件元数据等账号范围数据；先展示明确确认框，不退出账号、不删除凭据、不清除主题。
- “退出并清除登录信息”继续复用既有安全退出路径：清理内存 Cookie、系统安全存储凭据和当前账号缓存，再回到登录页。
- macOS 明示“关闭窗口只关闭窗口，不退出账号、不清除会话”，保持窗口生命周期和账户生命周期分离。

## 有意保留的边界

检查更新开关、Material You 动态配色、自定义壁纸和 Haze 玻璃态目前没有跨端生效链路。本次只显示准确的能力边界，不放置不会生效的假开关：

- Apple 端不复制 Android APK 下载更新流程，正式发布后使用 App Store、签名安装包或项目发布页。
- 四项自动同步已在 2026-08-01 接通：开关持久化；登录成功后始终先读缓存，再按开关拉取成绩、作业、课表和考试；首次失败等待 700 ms 自动重试一次。关闭开关时不会联网，也不会把空缓存界面永久留在加载态。
- 壁纸/Haze 与动态配色要在可访问性、性能和 Apple 平台视觉验证后单独实现。

- macOS 27.0：宽窗口卡片分组和两项数据操作实际显示；浅色主题即时切换成功。M6 随后完成真正的关窗保活实现：关闭只隐藏同一个 Compose 树，Dock/系统再次激活恢复原窗口，未触发退出或清理；详见 `docs/migration/m6-macos-lifecycle.md`。
- 为绕开 CAS 风控造成的视觉盲区，验收期间使用了不含真实凭据、不会写业务数据的临时设置预览入口；验收后已删除，安全扫描确认源码中不存在预览标记或示例账号，随后重新构建并安装正式认证版。
- 正式 iOS App 最终重新显示登录入口，账号、密码、保存选项和主按钮完整可见。2026-08-01 恢复有效会话后，登录后设置导航与真实账号缓存清理均已复测；临时预览证据不再承担这部分结论。

## 真实缓存清除与恢复往返

- 清除前只读数据库计数为成绩 26、课程 43、考试 9、作业 4，同步元数据 4，主题为 `Dark`，`PRAGMA quick_check=ok`。
- 在设置页点击“清除离线缓存”，确认框准确说明只删除当前账号离线副本、保留账号和主题；确认后页面反馈“离线缓存已清除；账号和主题仍保留”。
- 清除后成绩、课程、考试、作业、成绩筛选与同步元数据均为 0；主题仍为 `Dark`，应用仍停留在登录态，数据库 `quick_check=ok`。
- 依次进入成绩、课程表、考试和作业并手动重新同步，数据库恢复为 26/43/9/4；信息流重新建立四类基线且事件数为 0，没有把恢复数据误报为全部新增，`quick_check=ok`。
- 清除的是磁盘离线副本；当前进程中已经加载的页面工作集会保留到刷新或重启。成绩页首次进入时仍显示内存中的 26 条并提示同步失败，点击“重试”后同步成功。这一边界没有冒充“内存立即归零”，后续可在更改设置页与各模型的协调方式时再评估是否要即时清空界面。
- 设置页位于长滚动内容底部；用户以真实单指拖动确认页面可上下滚动并到达两项数据操作。Computer Use 的模拟触控拖动此前不稳定，因此不把自动化拖动写成通过证据。
